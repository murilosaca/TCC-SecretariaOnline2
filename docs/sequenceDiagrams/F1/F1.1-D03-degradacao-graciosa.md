# F1.1-D03 — Degradação graciosa (solicitações indisponíveis)

| Campo | Valor |
|---|---|
| HU | US-F1-001 |
| Escopo | erro parcial de módulo — CA-05 |
| Atores | Aluno, WebApp, JwtFilter, DashboardBFF, SolicitacoesQuery, FormativasQuery |
| Pré-condições | solicitações timeout/503; demais módulos OK |
| Origem | `docs/tcc-docs.md` §8.2 · CA-05 · RN-F1.1-01 |

## Passos

1. `GET /bff/dashboard/aluno` autenticado.
2. BFF tenta `SolicitacoesQuery` → falha; `FormativasQuery` (e demais) → OK.
3. BFF ainda responde **`200`**, com `solicitacoes: null` (ou equivalente).
4. WebApp: AlertBanner na seção de solicitações; resto do dashboard normal.
