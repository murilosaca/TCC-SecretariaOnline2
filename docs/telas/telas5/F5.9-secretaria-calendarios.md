# F5.9 — Calendários

**Rota:** `/secretaria/calendarios`  
**Fluxo:** F5  
**Shell:** AppLayout  
**Plataforma:** Web  
**Prioridade:** P2  
**Capability:** `calendar.manage`  
**API primária:** `/academico/periodos` (RF-F5-004-c)

---

## 1. Propósito

Períodos letivos e eventos de calendário acadêmico. Impedir sobreposição de
períodos e alertar ausência de período vigente.

## 2. Layout e estrutura (Auto Layout)

```
PageContent
  ├─ AlertBanner se não houver período vigente
  ├─ Tabs: Períodos | Eventos
  ├─ Calendar view mensal + lista
  └─ Modal evento / formulário de período (ano, semestre, início, fim)
```

## 3. Seções e conteúdo

Tipos de evento com cores semânticas. Período: ano + semestre {1,2} + intervalo.

## 4. Componentes DS/* obrigatórios

`DS/Calendar`, `DS/Modal`, `DS/DataTable`, `DS/AlertBanner`

## 5. Estados da interface

Month/week views | Loading | Empty | Error | Sem período vigente

## 6. Responsividade

Calendar scroll horizontal mobile

## 7. Acessibilidade (WCAG 2.1 AA)

Dias com aria-label

## 8. HATEOAS / ações condicionais

Ações por linha via `_links` — ocultar botão se rel ausente

## 9. Instruções Figma

Integrar componente Calendar. Usar pattern `Pattern/ListPage` na aba Períodos.
