# Frontend — Secretaria Online 2

React 18 + Vite (RNF-POR-01). Tipos futuros via `openapi-typescript` (RNF-CMP-01).

```bash
npm install
npm run dev
```

A aplicação sobe em `http://localhost:5173` e encaminha `/academico`, `/publico` e `/auth` para a API em `http://localhost:8080`.

Rotas oficiais (`docs/telas-figma.md`): `/login`, `/inicio`, `/secretaria/cursos|disciplinas|alunos|calendarios`, `/contato`.
